# 🀄 雀算 ― 麻雀 役判定・点数計算

14枚の手牌を**並べて選ぶだけ**。成立する役と翻・符を判定し、**親／子 × ロン／ツモ の4通りの点数を同時に**表示します。

## 🎴 入力

牌の選択ボードに34種すべてが並んでいます。上から順にクリックするだけで手牌に入り、残り枚数(4枚まで)も牌の右上に出ます。

- 最後に選んだ牌が**和了牌**になります。「和了牌」の列でいつでも変更でき、待ちの形(両面・嵌張・辺張・単騎・双碰)が変わると符も変わります
- 手牌の牌をクリックすると1枚戻せます。「1つ戻す」「クリア」「例を入れる」も用意
- 場風・自風、立直／一発／ダブル立直、海底・河底、鳴きの有無、ドラ表示牌と赤ドラ、ルール設定(喰いタン・切り上げ満貫・ダブル役満・連風牌の雀頭符)を切り替えられます

## 🧮 出す答え

| | ロン | ツモ |
|---|---|---|
| **親**(自風=東) | ○ | ○ |
| **子**(自風は選択) | ○ | ○ |

4つのマスは個別に計算しています。門前ツモが付くか、ロンで完成した刻子が明刻になるか、平和ツモが20符固定になるか — 条件で翻も符も変わるためです。マスを選ぶと、その場合の**役の一覧・符の内訳・支払いの内訳・手牌の面子分解**が下に出ます。

- 4面子1雀頭の分解を**全通り試し、いちばん高い解釈**を採用します(高点法)
- 七対子(25符固定)・国士無双・九蓮宝燈などの特殊形にも対応
- 国士無双十三面・四暗刻単騎・純正九蓮宝燈はダブル役満(設定でOFFにできます)

## 📋 役一覧

`#yaku` のページに、翻数・食い下がり・成立条件・**例の手牌**を並べています。牌はすべてSVGで描いているので、画像ファイルもフォントも要りません。

## ⚙️ 技術メモ・前提ルール

判定エンジン(`<script id="engine">`)はDOMに一切触らない純粋関数の集まりで、Node.jsから読み込んで単体テストできます。牌は0〜33の整数1つで表し、手牌は34要素のカウント配列として扱います。

- 前提は一般的なリーチ麻雀の標準ルール。喰いタンあり・後付けあり、連風牌の雀頭は2符、数え役満あり
- **未対応**:槓(暗槓・明槓・加槓)、天和・地和・嶺上開花・槍槓、流し満貫、裏ドラ、北抜き。14枚入力という形式上、槓を含む手は表現できません
- 鳴いた手は、符と三暗刻の判定のために「鳴いた刻子(ポン)」だけ指定してもらいます。チーは符にも役の暗刻数にも影響しないため指定不要です

# 🌴 漂流 ― HYORYU

名も知らぬ島に流れ着いた。**四十日後に嵐が来る**までに、**海へ出る**か、**ここで暮らす**かを決める。
島は**地点のつながり**でできていて、拠点を中心に放射状に広がっています。**ローグライク × マルチエンディング**のサバイバルです。

## 🗺 島は、踏んだぶんだけ生まれる

島は**六角の升**でできています。ただし最初から在るのではなく、**足を踏み入れた升だけがその場で生成**されます。

- 升を選んで発つと、そこの風景が**横スクロール**で開きます
- 隣に立ってはじめて、その先が**陸か海か**だけ見える。中身は踏むまでわかりません
- **海が出たら、その方角はそこで打ち止め**。海岸線は歩いて確かめるしかありません
- だから**島の広さも升の数も、最後までわかりません**。実際に毎回ちがい、小さいと18升、大きいと70升を超えます
- 道中では何かが起きます（転倒・獣・雨宿り・落とし物・見晴らし）
- 升の顔ぶれは砂浜・砂丘・岩浜・潮だまり・岬・密林・椰子林・藪・竹林・沼・滝・湧水・洞窟・断崖・獣道・座礁船・廃屋・石柱の丘の18種

> そして稀に ── **いくら歩いても海に出ない**ことがあります。

## 🏞 十八種の升に、それぞれの景色

升の種類ごとに**専用の景色**を描いています。同じ絵の色違いではありません。

- **滝** ― 岩壁を裂いて水が落ち、滝壺で砕けて靄になる
- **断崖・岬** ― 地面がそこで途切れ、はるか下に海と岩礁が見える（縁から先へは進めません）
- **座礁船** ― 腹を見せた船体が半ば砂に埋もれ、折れたマストが立つ
- **洞窟** ― 鍾乳石と、天井から落ちる雫。灯りがなければ足元しか見えない
- **石柱の丘** ― 傾いだ石の柱がいくつも
- **沼** ― 葦と靄と水たまり　**潮だまり** ― 岩に取り残された水鏡
- **獣道** ― 足跡が続く　**砂丘** ― 風紋　**廃屋** ― 崩れた骨組み

さらに、その升にいる**生きもの**がときどき横切ります ― 崖の海鳥、浜の蟹、獣道の猪、洞窟の蝙蝠、夜の蛾と蛍。

## 🎲 採るのは、賭け

**決まったものが決まった量出ることはありません。**

- 「さがす」たびに抽選。**空振りもあります**（「時間ばかりが過ぎた」）
- 探すほどその地点は荒れて出にくくなり、日が経つと少し戻ります
- 危ない地点ほど事故が起きます（滑落・虫刺され・落石・獣）
- 木の実と茸の**見た目と効き目の対応は漂流のたびにシャッフル**。「赤い実」が滋養か毒かは、食べてみるまでわかりません
- ただし**水だけは例外**で、水場に着けば探さずに飲めます。生き死にの基本まで運任せにはしません

## 🎒 持てる量には限りがある

重さの上限があり、**持ちきれないものは置いていくことになります**。編み籠と背負子で増やせます。
野営地の**置き場**に積めますが、**嵐や獣に荒らされます**。何を持ち帰り、何を諦めるか。

## ⛺ 野営地は動かせる

最初の野営地は漂着した浜。**行ったことのある地点なら、どこへでも移せます**（半日かかり、建てたものは失って材が半分戻ります）。

| 建てるもの | 要る立地 |
|---|---|
| いかだ | **浜**のある地点 |
| 狼煙台 | **眺望**のある地点 |
| 井戸と畑 | **水場**のある地点 |

浜に居続ければ漂着物は拾えるが水は遠い。水場に移せば楽になるが、いかだは組めない。**立地の取捨選択**がそのまま戦略になります。

## 📊 ゲージがない

進み具合を示す数値やバーは**ひとつも表示しません**。

- いかだ・小屋・井戸と畑・狼煙台が**実際に建っていく風景**が、そのまま進み具合
- 体の具合は上部の**4つのアイコン**の色だけ。数字は出ません
- **正気**は表示すらしません。削れると**画面の彩度が落ち、揺れ、いるはずのない人影**が立ちます
- 手記が「……そろそろ、海に出られる気がする」と教えてくれます

## ⏳ 四十日と、日暮れ

歩いても、探しても、移動しても**時刻が進み**、空の色が変わります。日が暮れると冷え、正気が削れ、獣が出る ―
**日没までに野営地へ帰れるか**をはかりながら、どこまで足を伸ばすかを決めることになります。

四十日目に嵐。それまでに決断しなければ、**海のほうが決めます**。

## 📖 19の結末

同じ「いかだで脱出」でも、**完成度・正気・海図の有無**で〈帰還者〉〈拾われた者〉〈海に消える〉に割れます。
定住も、正気が残っていれば〈島の民〉、擦り切れていれば〈隠者〉〈島になる〉へ。
死は結末ではなく**漂流記録**として別に残ります（**死んだら終わり**）。
そのうちひとつは、脱出でも定住でもありません。**歩いて出る**結末です。

一度知った**効き目は図鑑に残り**、次の漂流では正体不明の実から「⚠ 覚えのある匂い」を感じ取れるようになります。
答えそのものは持ち越せません ― 持ち越せるのは、**危険を嗅ぎ分ける勘**だけです。

## ⚙️ 技術メモ

- **Canvas 2Dだけ**。空・海・雲・地面・草木・建てもの・見取図まですべてコード生成（画像ファイルなし）
- 地図は**軸座標の六角格子**。陸か海かは「距離の減衰＋値ノイズ」で決まり、升は**初めて目にした瞬間に生成**されます（だから全体像はメモリ上にも存在しません）
- 経路と所要時間は、**踏んだ升だけを通る**ダイクストラ法
- 空と海の色は**時刻キーフレームの連続補間**。太陽と月は水平線から昇って水平線へ沈みます
- 地面は**シルエットをクリップしてから**地質ごとに塗るので、斜面に段差が出ません
- 正気の表現は、オフスクリーンに描いた1枚を `ctx.filter` で**彩度を落として合成**＋揺らぎ＋ヴィネット
- 音はすべて **Web Audio の合成**。音源ファイルはひとつもありません
  - 升ごとの環境音（波・滝・洞窟の低い唸り・風）が居場所に応じて混ざる
  - 昼は鳥、夜は虫、洞窟では雫 ― 時刻と地形で鳴くものが変わる
  - 地面の質で音色の変わる足音、焚き火の爆ぜ
- 図鑑と中断データは `localStorage`。**中断データは再開した瞬間に消えます**

> スマートフォンでも遊べます（縦持ちでは上段が島、下段が手記になります）。

# 🪨 枯山水 ― 光で描く石庭

白砂を熊手で掻き、石を据える。手を止めると、庭は **その場で書いたパストレーサー** によって
一枚の光の絵へと収束していきます。**HTMLファイル1枚・依存ライブラリゼロ**で、
影も、砂のくぼみに溜まる照り返しも、すべて本物の光の計算から生まれています。

## 🧹 庭を作る

- **熊手**: ドラッグした跡に砂紋が立ちます。筋は掻いた向きと直角に走り、**幅・目の間・深さ**を調整可能
- **石**: 砂の上をクリックで石を据える。つかんで動かせ、大きさ・高さ・向き・形を変えられます。石のまわりには自動で**波紋**が生まれます
- **波紋 / 苔 / ならす**: 好きな場所に同心円の砂紋を打つ、苔を生やす、砂紋を消して平らにする
- **庭組みプリセット**: **龍安寺**(五・二・三・二・三の十五石)・**三尊石**・**蓬莱島**・**まっさら**
- 作った庭は**ブラウザに保存**でき、**PNG画像**として書き出せます

## ☀ 光と季節

- **時刻スライダー**を動かすと、太陽が **北緯35°(京都)の実際の太陽位置計算** に従って空を移動します
  （季節から赤緯、時刻から時角を求めて高度・方位角を算出）
- 夕暮れには影が長く伸び、日没後は**月あかり**に切り替わり、星が瞬きます
- **春夏秋冬**で砂・苔・土・空の色、落葉の量が変わります(冬は雪化粧)
- 塀の向こうには **借景** ― 遠山の稜線が、距離に応じた大気遠近で霞みます

## ⚙️ 技術メモ ― 1ファイルのパストレーサー

- **WebGL2 のフラグメントシェーダで書いた単方向パストレーシング**。太陽への **NEE(明示的光源サンプリング)** ＋ コサイン重点サンプリングの拡散反射バウンス ＋ ロシアンルーレット打ち切り。float テクスチャに**累積**し、静止している間ずっと収束し続けます
- **砂は本物の起伏**です。1536×1024 の高さフィールドを持ち、専用のハイトフィールドマーチャ（光線が地形に追いつく速度から次の一歩を決める方式）で交差判定。だから砂紋の谷は**自分自身に影を落とし**、低い夕日ほど筋が浮かび上がります
- 高さフィールドは CPU 側で**法線まで焼いて RGBA8 に詰めて**あるので、シェーダは1点あたり1回のフェッチで済みます。掻いた矩形だけを `texSubImage2D` で差分アップロード
- 石は**SDF(符号付き距離場)** ＋ 値ノイズ変位。バウンディング球で遠い石を早期棄却
- 空は太陽高度で切り替わる解析モデル。**太陽の日面をサンプリング**するので影はやわらかく、地面に落ちる**照り返し(大域照明)**が陰の中まで回り込みます
- 操作中は**ノイズのない直接光プレビュー**、手を止めた瞬間にパストレースへ切り替え。**GPUの速さを実測して内部解像度を自動調整**します
- 音はすべて Web Audio の合成 ― 松風、**鹿威し**の音と水音、熊手の摩擦音、そして倍音を組んだ**梵鐘**(撞くと12秒かけて余韻が唸ります)

> ⚠ WebGL2 が必要です(Chrome / Edge / Safari 15+ / Firefox)。

# 📈 KATA ― チャート形状スキャナ

ローソク足チャートを読み込むと、そこに潜む **チャートパターン（型）を機械的に検出してハイライト** するツールです。ジグザグの高値/安値（スイングポイント）を抽出し、そこから各パターンの幾何条件を判定します。**検出処理はすべてブラウザ内で完結**（＝ネット不要で確実に動く）のが最大の強みです。

## 🔎 検出できる型

| パターン | 向き | 判定の要点 |
|---|---|---|
| **三尊天井 / 逆三尊**（ヘッド&ショルダー） | 弱気転換 / 強気転換 | 3山（3谷）で中央が最も高い（低い）、両肩がほぼ同値、ネックラインがほぼ水平。ネック抜けで確定 |
| **ダブル / トリプル トップ・ボトム** | 弱気 / 強気転換 | ほぼ同値の山（谷）が2〜3回、間に十分な谷（山）。ネック抜けで確定 |
| **三角保ち合い / ウェッジ** | 中立 / 放れ方向 | 直近の高値・安値に回帰直線を当て、収れん（対称・上昇・下降・ウェッジ）を判定 |
| **サポート / レジスタンス** | ― | 反発・反落した価格帯をクラスタリングして水平線を描画（タッチ回数=強さ） |

各検出には **信頼度スコア**（対称性・水平度・タッチ数・ネック抜けの有無から算出）と、**概算の値幅目標** を表示します。

## 🗂 3通りのデータ入力

1. **デモ**（既定・即動作）: 三尊/逆三尊/ダブル/三角/ランダムの合成チャートで、検出の挙動をその場で体験
2. **CSV読み込み**（ネット不要・確実）: 証券会社やTradingViewの OHLC CSV を読み込み。ヘッダ(`date,open,high,low,close,volume`)は自動判別、区切りは カンマ/セミコロン/タブ 対応
3. **ライブ取得**（任意・APIキー）: Twelve Data / Alpha Vantage の**無料キー**を設定するとティッカー指定で取得。これらは **CORS対応**なのでブラウザから直接・安定して取れます（キー不要系はCORSで弾かれるため非対応）

- **感度スライダー**で検出の厳しさ（スイング抽出の窓＋許容誤差）を5段階調整。だまし回避のため既定はやや厳しめ
- パターン種別ごとに **表示のオン/オフ**、カードをクリックで該当パターンをチャート上で強調

## ⚙️ 技術メモ

- ジグザグpivot抽出（フラクタル極値＋交互性の整理）→ パターンごとの幾何判定、という素のJSアルゴリズム。外部ライブラリ・チャートライブラリなし、Canvasで自前描画
- ATR基準のスケール対応許容誤差で、値位の違う銘柄でも同じ感度が効くように
- ⚠ 検出はあくまで機械的な形状マッチで、だましや主観の余地があります。**投資助言ではありません**

# 🦊 どうぶつがっこう ― さんすう・こくご × どうぶつ

ある子どもの「**さんすう・こくご(けいさん)がもっとわかるアプリ**」と「**どうぶつのたべものやとくちょうがわかるアプリ**」という2つの願いを、1つに融合したこども向け知育アプリです。

- **さんすう**: たしざん・ひきざん、どうぶつが登場する文章題。大きな3択ボタンで直感的に
- **こくご**: もじの かず・はじめの おと・はんたいことば・なかまさがし(絵つき)
- **ごほうび**: 正解するとどうぶつと仲良くなり、数問ごとに**新しいどうぶつが登場**。その子が知りたかった **たべもの・とくちょう** が どうぶつ図鑑に増えていく(全20種)
- **やさしさ設計**: ぜんぶ ひらがな、大きなボタン、紙吹雪とほめ言葉、**こわい不正解なし**(まちがえても「もういちど！」、2回で答えをそっと教える)。⭐と進み具合は保存されます

> 手描きの絵は描けず泣いてしまった子の、言葉だけの願いから起こしたアプリです。学ぶ楽しさと、どうぶつを知るワクワクが一緒になりますように。

# 🐣 めばえ ― いきもの工房

手描きのUIスケッチ(いきものの作成・登録・図鑑)から着想した、**いきもの創造＆コレクション**アプリです。

- **こうぼう(工房)**: からだ・め・くち・あたま飾り・て・あし・もよう・いろ の8スロットを ◀▶ で選び、あなただけのいきものをプロシージャル生成。🎲でランダム、なまえをつけて「うみだす」
- **ずかん(図鑑)**: 生み出したいきものが一覧に。タップで詳細(種族・特徴・うまれ日)。「にがす」で手放すことも
- **おうち**: 登録したいきものが草原のおうちで歩きまわり、ぴょこぴょこ暮らす。タップすると跳ねて名前をふきだす
- すべてのいきものは遺伝子(genome)から**同じ描画関数**で描かれ、組み合わせは無限。図鑑・おうち・工房・詳細のどこでも同じ姿で登場します
- 作成したいきものは**ブラウザに保存**され、次回も残ります

# ☯ 縁起 ― Form vs Emptiness(対戦ゲーム)

「すべては空(くう)。だが縁(えん＝つながり／縁起)があるから形がある」という色即是空の思想を、**対戦ボードゲーム**にしたものです。

## ♟ ルール

ヘックス盤上のすべては、本来 **空**。形は **源(みなもと)への縁** があるときだけ存在できます。

- **色派**(あなた or AI): 手番に節点を灯し(隣の形へ自動で縁が結ばれる)、**3つの縁座(ゴール)すべてに形を灯せば勝ち**
- **空派**: **縁を1本断つ**。源へのつながりを断たれた形は **連鎖して滅する(縁滅)**。色の完成を19局まで防げば勝ち(=無常が勝つ)
- **断たれた縁は数手ののち結び直される**。だから**縁を輪(ループ)に厚く結べば、一手では崩れない** ― 「深い縁起ほど、形は強い」という戦略性が生まれます

### モード

- **ひとり ― 試練(ソロキャンペーン)**: あなたは色。**序 → 破 → 急 → 転 → 妙 → 空** の6ステージを、しだいに強くなる空(1手先読みの思考＋縁座を狙い撃つ否定戦略)＆縮む制限局数で攻略します。突破すると次の試練が開き、進行はブラウザに保存されます
- **自由対局**: 「色」「空」「観戦(AI対AI)」を選んで対局(互角設定 ・ AI対AIで色52%/空48%)

盤上のバランスは、断縁を「永続」にすると縁座が復活不能=色が構造的に必敗になることを検証で突き止め、**縁の回復(ヒール)** で解決しています(だから難易度は"局数と空の賢さ"で調整、"断つ数"は増やしません)。

## 🛠 技術メモ

- グラフ連結性(源からの到達可能性)を毎手 BFS で判定し、**連鎖崩壊(縁滅)** を計算
- 断縁の**回復(ヒール)**により、永続劣化ではなく動的な綱引きに(これがないと空が必ず勝つ設計だったのを検証で発見・修正)
- 色AIは **2連結の塊**を育てて複数の源に接続、空AIは**最も崩落を招く縁**を探索。合成音のシンギングボウル(形の生成)と重い余韻(縁滅)

# 🌏 TERRA — 生きている大地

地形を隆起させ、雨を降らせ、木を植え、動物を放つ。あとは眺めるだけで生態系が勝手に動き出す「箱庭テラリウム」です。

## 🌱 世界のしくみ

- **草 → ウサギ・シカ → キツネ** の食物連鎖が本当に演算されています。獲物が減ればキツネは飢え、捕食者が消えれば草食動物が草原を食べ尽くす ― 個体数は現実の生態系のように波打ちます
- **四季と昼夜**が巡ります。春は桜が咲いて花びらが舞い、夏の夜は蛍が光り、秋は紅葉が散り、冬は雪が積もって動物たちは冬ごもり。雪解け水は春に湖へ流れ込みます
- **水は物理シミュレーション**。雨は谷に集まり、湖をつくり、土を潤し、日照りには蒸発します
- **山火事**: 落雷(自然発生もします)で森が燃え、風向きで延焼し、雨が消し止めます
- 絶滅しても大丈夫。環境が回復すれば、動物たちは**外の世界から移住**してきます

## 🎮 操作(TERRA)

| ツール | 効果 |
|---|---|
| 🏔隆起 / ⛏掘削 | ドラッグで地形を変える(山を作ると寒くなり雪が積もる) |
| 🌧雨 / 🌱草 / 🌳木 | 環境を育てる |
| 🐇🦌🦊🐦 | 動物を放つ |
| ⚡雷 / ☄️隕石 | 破壊と再生 |
| 筆 / 速度(1〜8×) / 停止 | ブラシサイズ・時間操作 |

サウンドはすべてWeb Audio合成: 風・雨・小鳥のさえずり(昼)・虫の声(夏の夜)・雷鳴。

# 🌊 ABYSS — 深海10,911mへの潜航

海面からチャレンジャー海淵の最深部まで、実際の深度に沿って潜っていく没入型の深海探査体験です。

## 🤿 体験の流れ

- **潜航艇「ABYSS-01」を操縦**し、マウスで探照灯を照らしながら深海へ
- 深度に応じて実在の生物が登場 ― マイワシの群れから、リュウグウノツカイ、チョウチンアンコウ、ダイオウイカ、そして水深8,000mのシンカイクサウオまで
- **クリックで撮影**すると図鑑に記録。全26種(生物22種+ランドマーク4つ)のコンプリートを目指せます
- 深度とともに光が消え、水温が下がり、水圧が増していく。1,000mを超えると完全な闇 ― 頼りは探照灯と、生物自身の**生物発光**だけ
- 水深2,500mの**熱水噴出孔**、3,800mの**沈没船**、5,200mの**鯨骨生物群集**などのランドマークが待っています
- 光を怖がって逃げる魚、逆に光に誘われて近づいてくるチョウチンアンコウ、照らすと青い警報を光らせるクロカムリクラゲなど、生物ごとの反応の違いも
- 発見記録と最深到達深度は**ブラウザに保存**され、次回に引き継がれます

## 🎮 操作(ABYSS)

| 操作 | 効果 |
|---|---|
| **マウス** | 探照灯の向きと機体の操作 |
| **ホイール / W・S** | 潜航・浮上の速度調整 |
| **クリック** | 撮影(図鑑に記録) |
| **Space** | その場で停止 |
| **H** | UI表示切替 |

## ⚙️ 技術的なポイント(ABYSS)

- 26種すべての生物を**プロシージャルなCanvas描画**で表現(画像ファイルゼロ)。図鑑のサムネイルも同じ描画関数から動的生成
- `destination-out` 合成による**探照灯のライティング**と、闇を貫く生物発光のグローパス
- セグメントチェーンによるリュウグウノツカイ・フクロウナギの**リボン状の泳ぎ**
- Web Audio APIで**完全合成した環境音** ― 深度で変化する水中ノイズ、深海での船体のきしみ、クジラの鳴き声、ソナーピング
- 深度連動の色調・マリンスノー・海溝の岩壁・ゾーン演出、実話ベースの深度マイルストーン表示

# 🌌 GALAXY FORGE — リアルタイム銀河シミュレーター

最大 **12,000個の恒星** がリアルタイムに重力演算され、クリック＆ドラッグでブラックホールを射出して、銀河を自在に崩壊・衝突・再構築できます。

## 🎮 操作方法

| 操作 | 効果 |
|---|---|
| **クリック＆ドラッグ** | ブラックホールを射出(引いた方向と距離が初速になります) |
| **Space** | 時間の一時停止 / 再開 |
| **C** | すべてのブラックホールを消去 |
| **H** | UIの表示 / 非表示(スクリーンショット用) |

## 🪐 プリセット

- **渦巻銀河** — 3本腕のスパイラル銀河。中心核の周りを恒星がケプラー軌道で公転
- **銀河衝突** — 2つの銀河が衝突コースへ。核同士は合体してより巨大なブラックホールに
- **リング星雲** — 恒星がリング状に公転。摂動を与えると美しく崩壊します
- **カオス** — 無重力空間に恒星を散布。ブラックホールを投げ込んで銀河を"鍛造"してください

## 🎛 コントロール

- **恒星の数** (500〜12,000)
- **重力の強さ** / **時間の流れ** / **光の残像**(軌跡の長さ)
- **宇宙のサウンド** — Web Audio APIで完全合成したアンビエントドローン。ブラックホールの生成・合体時には質量に応じた音程のピングが鳴ります

## ⚙️ 技術的なポイント

- **Canvas 2D + 加算合成** による恒星のグロー表現と残像トレイル
- **Structure of Arrays** (`Float32Array`) による粒子データ管理で毎フレーム最大12,000粒子を60FPSで更新
- 色相バケツごとの **バッチ描画** で `fillStyle` 切り替えを最小化
- ソフトニング付き重力 + **サブステップ積分** で高速時間でも軌道が安定
- ブラックホール同士の **合体** と、事象の地平面に落ちた恒星の **降着**(質量が成長)
- **Web Audio API** で外部音源なしのアンビエントサウンドを合成
- レスポンシブ対応(モバイルはタッチ操作 + パネル折りたたみ)
